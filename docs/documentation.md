# 分量の確認範囲

Markdownは本文，補助資料，案内をすべて数える．
25行・1,200文字超は理由のないまま残さない．
日本語1行40文字超は警告として文脈を確認する．
依存パッケージと実行時の生成物は対象外とする．

原著者の声明と帰属表示は原文を保持する．
固定した試験用プロトコルと合成応答の説明も保持する．
選定プロンプトは判断条件と出力契約を保つ．
10種類の依頼を細切れの資料へ移して数値を満たさない．
例外5件の理由と原文のハッシュを[設定](../documentation-exceptions.json)に残す．
原文を変更すると再確認が必要になり，機械的確認は失敗する．
例外もファイルごとの行数・文字数を報告する．

```sh
uv run --locked python scripts/check_repository.py --json
```

Codexの共通Stopフックは.agentsだけを確認する．
本派生版は上の確認コマンドとCIで全資料を確認する．
