# 確認範囲

全Markdownの分量，例外，リンク，登録先を確認する．
補助資料の超過と登録漏れを検出する回帰試験も置く．
Pythonは保持した文献ツールとガードの既存試験を実行する．
Piは指示の合成，コマンド引数，5スキルの登録を確認する．
SessionStartが旧工程を自動起動しないことも確認する．

削除した旧工程の契約テストは対象から外した．
既存ツールの挙動を確認するテストは保持する．
モデル構成は固定の推奨文ではなく入力設定を試験する．
ガードの実装・設定・既存テストは変更しない．

[選択条件の比較](selection-review.md)は文章上の比較である．
モデルの研究判断や文献選定の精度は評価していない．
文献APIへの実通信や実際の研究データは使っていない．
Piの実行環境試験はモデルを呼び出さない．
