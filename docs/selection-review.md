# スキルの選択条件の比較

同じ依頼を旧版と新版の責任範囲に当てはめて比較した．
モデルを別セッションで動かした選択精度の測定ではない．

| 依頼 | 旧版 → 新版の担当 |
| --- | --- |
| 研究の問いを絞る | deep-research → 同じ |
| 未調査の先行研究を探す | deep-research → 同じ |
| 資料から仮説の反証を探す | deep-research → 同じ |
| 手元の論文群からレビューを書く | academic-paper → 同じ |
| 原稿の要旨を書く | academic-paper → 同じ |
| 査読への返答を直す | academic-paper → 同じ |
| 原稿を変更せず問題を指摘する | reviewer → 同じ |
| CSVの抄録を採否判定する | sr-screener → 同じ |
| 系統的レビューの検索方針を立てる | deep-research → 同じ |
| 研究から原稿まで進める | pipeline → 同じ |
| 既読申告を記録・取消する | 専用スキル → 補助ツール |
| 検証キャッシュを削除する | 専用スキル → 補助ツール |
| 利用環境を確認する | 専用スキル → 利用環境の標準機能 |
| 一般のメールを推敲する | 対象外 → 同じ |
| 研究と無関係なコードを直す | 対象外 → 同じ |

reviewerとpipelineは表中だけの略記である．
短縮による実際の選択精度や研究品質の改善は未測定．
