# 簡素化の判断

本文を短くするだけでは補助指示の重複が残った．
各仕事の判断は5つのSKILL.mdへ集める．
固定人数・固定工程の進行と自動監査は廃止する．
使わなくなった役割，工程資料，契約テストは削除する．
削除した資産は[上流コミット](../UPSTREAM.md)に残る．

文献検索・選定・既読記録の補助ツールは保持する．
skills/にある既存の別名も互換用に保持する．
書込みガードと秘密情報の検出は変更しない．
文献選定の複数担当は明示的に使う任意の補助機能とする．
ガードの対象だった旧担当名の制限も保持する．
公開エージェントは読み取り専用にして結果を返す．

既存ツールの出力形式と旧版の全工程は区別する．
旧版の自動最終化や書式保証は提供しない．
旧版を短く見せるための別ファイルへの移動はしない．
