# Piでの利用

リポジトリ全体を取得し，ルートで起動する．

```sh
pi -e ./pi
```

標準のスキル選択で，依頼に合うSKILL.mdを読む．
明示する時は/skill:academic-paperのように指定する．
利用環境の確認はcheck-research-environmentに依頼する．
開始・停止用の独自コマンドは使わない．

ClaudeのフックはPiでは動かない．
書込みガードが有効だとは報告しない．
複数担当やWeb検索は利用環境が提供する場合だけ使う．
同じ会話で担当を演じ分けても独立した査読にはならない．
実際のPiでの確認にはPI_CODING_AGENT_ROOTを指定する．
