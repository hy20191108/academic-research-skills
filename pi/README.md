# Piでの利用

リポジトリ全体を取得し，ルートで起動する．

```sh
pi -e ./pi
```

/ars-pi-startで有効化，/ars-pi-stopで解除する．
/ars-pi-doctorで利用できる機能を確認する．
/ars-*と5つの/skill:名から依頼できる．
スキルの内容は親ディレクトリの原本を読む．

ClaudeのフックはPiでは動かない．
書込みガードが有効だとは報告しない．
複数担当やWeb検索は利用環境が提供する場合だけ使う．
同じ会話で担当を演じ分けても独立した査読にはならない．
実際のPiでの確認にはPI_CODING_AGENT_ROOTを指定する．
